# FullOps Squad 0.7.4 변경안

## 범위

실제 사용 레포에서 coordinator가 과제를 Jev로 분류한 직후 대화가 요약(context compaction)되자, 배정을 잊고 Run 상태만 확인한 채 턴을 끝냈다. 새 세션이라 터미널이 바뀌어 Run 연결도 끊겨 있었다.

## 변경

- flow-gate가 세션 안에서 실행한 `jev_route.py --key <키>`를 기록한다. 세션을 끝낼 때 그 키가 인박스·작업 로그·`PLANS.md` 어디에도 없으면 한 번 막고, route 기록을 다시 읽어 배정을 이어 가거나 `PLANS.md`에 보류 사유를 적으라고 알린다. 세션 상태는 세션 ID로 저장해 대화 요약 뒤에도 남는다. 같은 상태로 다시 끝내면 통과한다.
- `fullops-orca`: 새 coordinator 세션에서 `orchestration check`가 "no longer bound"를 반환하면 기록한 run id로 `orchestration run-use --id <run id>`를 실행해 다시 연결한다.

## 검증

`tests/flow-gate.py`에 배정 누락 사례를 더했다. `npm test`가 통과했다.
