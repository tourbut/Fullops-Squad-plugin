# 1.4.3 — 보드 이슈 목록과 검증 증거 재사용

## 변경

- 보드에서 해당 GitHub 저장소의 이슈 목록을 표시하고 클릭하면 원래 이슈 페이지로 이동한다.

- lint는 최근 실행 결과를 작업 트리별 Git 디렉터리의 `fullops-gate/lint-result.json`에 보존한다. 새 시도가 시작되면 이전 최신 결과를 무효화한다.
- `review.py prepare --lint <결과 JSON>`은 같은 base·HEAD·기준 설정의 유효한 검사 증거를 원본 그대로 가져온다. 테스트를 다시 실행하지 않는다. 환경·의존성 동일성은 검토자가 확인하며 확인 불가이면 필요한 검증을 수행한다.
- review check는 테스트뿐 아니라 등록된 모든 검사 명령의 누락·중복·추가·통과 종료코드를 확인한다. 기존 필수 검사의 증거 누락을 막는 보완이며 테스트 수준·심각도를 올리지 않는다.
- done/flow hook은 세션별 호출 근거와 오류 종류를 Git 디렉터리에 기록한다. 일반 오류는 같은 종류를 세션당 한 번 알리고 작업은 계속한다. `done_gate.py status`는 stdin의 `cwd`·`session_id`에 해당하는 기록을 읽으며 조회 자체를 실행 증거로 남기지 않는다. 기록 없음은 unknown이다.
- 기존 테스트 러너·fixture·매개변수 사례를 우선 재사용한다. 개발 중 변경 경로 검사와 안정된 통합 후보의 전체 회귀를 구분하고 역할별 중복 실행을 줄인다.
- 리뷰 보고서에서 지시 범위와 실제 diff, 테스트 약화 근거, 재사용 증거의 환경을 함께 확인한다. 대체된 결정은 역할 context에서 새 결정에 연결한다.

## 기존 레포 적용

1. 마켓플레이스 플러그인을 업데이트하고 새 세션에서 명시적인 `update-fullops` 요청으로 적용한다. 기존 역할·검사 수준·필수 명령·예외·사용자 설정을 보존한다.
2. 기존 `lint.json`의 `kind: test` 명령을 프로젝트의 실제 실행 범위와 비교한다. 변경 경로용 기존 명령을 우선 사용하고 전체 회귀의 최소 `level`·담당·시점을 분류한다. 레벨 없는 기존 명령과 `required: true`는 그대로 실행되므로 일괄 약화하지 않는다. 부분 실행을 지원하지 않으면 그 한계를 기록한다.
3. `rules/common/testing.md`, `lint/README.md`, `review/_REPORT.md`의 필요한 절만 통합한다. 진행 중 지시서의 기존 실패·최종 수락 기준은 유지한다. 다음 작업부터 기존 lint 결과를 재사용하고 원본 SHA·환경 확인 근거를 기록한다.
4. 새 세션에서 기존 hook 이벤트가 실행된 뒤 같은 세션 ID로 status를 확인한다. 실행되지 않는 hook이나 기록 저장 실패는 자신을 보고할 수 없으므로 unknown을 정상으로 처리하지 않는다. 수락은 기존 lint·review 증거로 확인한다. 호스트 권한을 자동 확대하지 않는다.
5. 보드 이슈 목록을 사용하려면 보드를 다시 생성하고 저장소 연결 및 GitHub 조회 인증 상태를 확인한다.
6. 적용 결과·해당 없음·보류 이유를 기존 업데이트 기록에 남긴다. 설치 성공과 저장소 적용 완료를 구분한다.

## 검증과 한계

#27의 기존 테스트 파일에 증거 재사용·불일치 거부·hook 오류 1회 안내·unknown 구분 사례를 통합한다. 별도 테스트 프레임워크·토큰 측정 게이트·AI 검증 호출은 추가하지 않는다.

기존 테스트 수준 선택·전체 회귀 지연·경고 심각도는 유지한다. 다른 SHA의 증거를 새 실행으로 간주하는 자동 캐시는 도입하지 않는다. 일반 환경·외부 서비스 동일성을 자동 판정하지 않는다.

호스트 sandbox, 범용 명령 차단기, 외부 작업 관리자, 정기 기억 정리는 제외한다. 읽기 전용 리뷰의 기존 clean 검사와 OS 권한 제한은 별개이며 새 호스트별 격리 계층은 만들지 않는다. 이슈 질문 outbox의 불확실 전송 방어는 이미 있으므로 유지한다. 범위 이탈·assertion 약화의 의미 판단은 기존 리뷰에 맡긴다. 기존 권한·비밀값 경로에 대해 이번 변경으로 새로운 포괄적 보호를 주장하지 않는다.
