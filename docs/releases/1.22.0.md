# 1.22.0 — 긴 Bash 출력 줄이기

#104 후보 A를 Claude Code에 넣었다. 모델을 부르지 않는다.

## 변경

- **`output_trim.py`:** 성공한 Bash 호출의 stdout이나 stderr가 400줄을 넘으면, 처음 80줄, 끝 80줄, 오류로 보이는 줄 최대 80개만 모델에 보낸다. `flow_gate post`가 `updatedToolOutput`으로 교체한다.
- **원문:** `.fullops-squad/local/outputs/output-NN.txt`에 저장하고 경로를 출력 맨 앞에 적는다. 슬롯 20개를 돌려 쓰므로 오래된 원문은 덮어쓴다. 같은 폴더의 `trim.jsonl`에 원문과 전송 글자 수를 남긴다.

## 알아 둘 점

- 실패한 호출과 중단된 호출의 출력은 그대로 간다. Codex·grok과 PowerShell 도구에서는 동작하지 않는다.
- 끄는 설정은 없다.
- 절감량은 아직 재지 않았다. 원문을 다시 읽으면 절감분이 사라질 수 있다. `trim.jsonl`로 잰 뒤 #104 후보 B를 정한다.
- 원문 파일에는 명령 출력이 그대로 남는다. 비밀값이 출력된 명령이면 그 값도 남는다.
- 반복 줄과 JSON 배열 접기는 넣지 않았다.

## 기존 설치 적용

- 플러그인을 1.22.0으로 갱신한 뒤 새 패키지의 `scripts/deps.py --host <현재 CLI>`를 실행한다. 이어서 `scripts/deps.py --check --host <현재 CLI>`로 확인한다. Claude Code는 사용자가 `/reload-plugins`를 실행한 뒤 같은 세션에서 이어갈 수 있다.

## 기존 레포 적용

필수 적용은 없다. `.fullops-squad/.gitignore`에 `local/`이 있는지 확인한다(1.8.6부터 템플릿에 있다).
