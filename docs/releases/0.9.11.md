# FullOps Squad 0.9.11

## 변경

- npm 실행 파일 `fullops-squad`에 install·update·check 명령을 제공한다. 기본 대상은 PATH에 있는 Codex·Claude Code·grok이다.
- 각 CLI의 공식 마켓플레이스 명령으로 설치한다. Claude Code의 의존 마켓플레이스도 등록하며 다른 출처로 등록된 동일 이름은 덮어쓰지 않는다.
- 기본 Codex 홈, 현재 CODEX_HOME, 기존 Windows Orca 홈을 중복 없이 처리한다. 다른 환경의 추가 홈은 --codex-home으로 지정한다.
- 설치된 플러그인의 deps.py로 외부 의존성을 설치·검사한다. 업데이트 시 의존성 목록이 같고 필수 도구가 있으면 재설치를 생략한다.
- --dry-run은 읽기 전용 계획을 출력한다. --repo는 설치 후 릴리스 적용 안내를 출력하며 서비스 레포를 수정하거나 setup하지 않는다.
- 한 대상의 실행 실패는 요약하고 다른 대상을 처리한다. 실패가 있으면 종료코드 1을 반환한다.

## 기존 레포 적용

이 릴리스는 글로벌 설치 편의 기능이다. 기존 서비스 레포의 역할·제품 코드·검증 기준 변경은 필요 없다. 업데이트 기록에 해당 없음을 남기고, 이전 릴리스의 미적용 항목은 update-fullops로 계속 처리한다. 설치 후 새 세션을 사용하며 진행 중 worker를 중단하지 않는다.

npm 패키지는 CLI·의존성 목록만 포함한다. 플러그인 본문은 GitHub 마켓플레이스에서 받는다. npm 공개 전에는 로컬 패키지 또는 GitHub 패키지 실행 방식을 사용한다.
