# FullOps Squad 0.8.1 변경안

## 범위

Jev가 작업 난이도에 맞춰 역할별 모델·effort를 고르게 한다. 에이전트가 코딩 작업을 끝까지 수행하도록 지시서 규칙을 보강하고, 셸 PATH에 python3·orca가 없는 환경을 보완한다.

## 모델 선택

- `orca-agents.md`의 `## 모델 후보`에 역할마다 `` - `역할` `에이전트` `모델` `effort`: 언제 쓰는지 `` 줄을 약한 것부터 강한 순으로 적는다. 코드 블록 안의 예시는 읽지 않는다.
- `jev_route.py`가 배정 역할의 후보를 레벨(1이 가장 약함)과 제공사(claude=anthropic, codex=openai, grok=xai, agy=google)로 Jev에게 넘겨, 작업을 해낼 수 있는 가장 낮은 레벨을 고른다. 후보가 하나면 그대로 쓰고, Jev가 실패하면 가장 강한 후보를 쓴다.
- 설계를 거친 과제는 지시서마다 `jev_route.py --model-only --role <역할>`로 다시 고른다. 결과는 `worker-start --agent/--model/--effort`로 적용하고, `--model`이 없는 CLI는 `terminal create --command`로 띄운다.
- 현황판 역할 카드에 선택된 모델을 표시한다.

## 지시서 규칙

- 목표와 완료 조건을 한 지시서에 적고 끝까지 맡긴다. worker는 레포 밖 변경·삭제·force-push·소유권 밖 수정·승인 범위 초과·설명되지 않는 검증 실패일 때만 멈추고 묻는다.
- 지시서와 dispatch spec에 사고 지시("신중히 생각해")를 넣지 않고 난이도는 모델·effort로 조절한다.
- 디자인 지시는 피할 스타일을 구체적으로 적는다. 큰 감사·리팩토링은 모듈 단위로 나눠 병렬로 맡긴다.
- coordinator는 보고를 그대로 믿지 않고 SHA·종료코드·산출물을 확인해 표로 남긴다. worker는 `해야 할 일`을 끝낼 때마다 체크해 대화 요약 뒤에도 상태를 되찾는다.

## 경로 보완

- `orca_wait.py`와 flow-gate가 `ORCA_CLI_COMMAND`, PATH, OS별 기본 설치 경로 순으로 orca를 찾는다.
- 세션 시작 안내에 python3·orca 전체 경로를 적어, 샌드박스 셸이 사용자 PATH를 받지 못해도 명령을 실행할 수 있게 한다.

## 기존 레포

모델 선택은 `## 모델 후보`를 적어야 동작하며, 없으면 배정표 기본값을 쓴다. 지시서 템플릿 변경은 `setup-fullops` 갱신으로 반영된다. 플러그인 업데이트 뒤 세션을 새로 연다.
