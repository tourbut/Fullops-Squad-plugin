# 1.22.1 — hook 런타임 검사의 오탐 수정

## 변경

- **`hook_runtime.py`:** 패키지 내용을 비교할 때 `.in_use/`를 뺀다. Claude Code는 실행 중인 세션마다 설치 폴더에 이 표지를 둔다. 그래서 다른 세션이 뜨거나 끝나면 hook은 정상인데 `deps.py --check`가 `hook runtime missing or outdated`로 실패했다.

## 알아 둘 점

- Orca 프로필에서 나는 `host dependency installation incomplete` 실패는 이 수정으로 풀리지 않는다. 프로필의 `fullops-deps.json`이 `~/.claude` 사본으로 바뀌면 그 안의 `home` 값이 현재 설정 폴더와 달라져 실패한다.

## 기존 설치 적용

- 플러그인을 1.22.1로 갱신한 뒤 새 패키지의 `scripts/deps.py --host <현재 CLI>`를 실행한다. 이어서 `scripts/deps.py --check --host <현재 CLI>`로 확인한다. Claude Code는 사용자가 `/reload-plugins`를 실행한 뒤 같은 세션에서 이어갈 수 있다.

## 기존 레포 적용

필수 적용은 없다.
