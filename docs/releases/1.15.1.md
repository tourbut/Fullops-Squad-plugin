# 1.15.1 — 모션 템플릿 5종 추가

이슈 #57 댓글로 추가된 공개 프롬프트 5건의 구조를 `fullops-motion/templates.md`에 #12–#16으로 더한다. 기존 템플릿처럼 원문은 싣지 않고 제작자와 원본 링크만 남긴다.

## 변경

- **#12 사물 분해 해설 영상**: 내레이션 교체만으로 현지화하는 장편 해설. 3분이 넘으므로 장 단위 HTML로 나눠 렌더한다.
- **#13 캐릭터 하나의 다섯 세계 여정**: 비트 위 매치컷 모핑. 원문에 없는 비트 그리드와 사전 점검을 채운다.
- **#14 스위스 에디토리얼 디더링 쇼릴**, **#15 리퀴드 크롬 쇼릴**: 스타일 문단을 고정한 쇼릴. 효과음은 사용자가 준 실제 음원만 쓴다. #15의 HDR 출력은 사용자가 확정할 때만 별도 FFmpeg 인코드로 만든다.
- **#16 기능 타일 마이크로 애니메이션**: 웹사이트 벤토 그리드용이다. 사이트 구현이면 `fullops-frontend`로 넘기고, 영상으로 낼 때만 `seek(t)` 타임라인으로 바꾼다.

## 기존 레포 적용

플러그인 업데이트 후 세션을 새로 시작한다. 별도 설정 변경은 없다.
