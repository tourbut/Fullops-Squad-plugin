# 1.14.1 — Orca 1.4.246 평면 worker 응답 호환

Orca 1.4.246의 `worker-show`·`worker-list`는 `projection` 객체 없이 필드를 평면으로 돌려준다. FullOps가 이전 형식만 읽어 생긴 문제를 고친다(#118).

## 변경

- **worker 도구 호출 거부 해결**: 이슈 자동 모드를 한 번 켰던 레포에서 모든 dispatch worker의 Bash·PowerShell 호출이 `worker의 정본 task를 확인하지 못했습니다`로 막히던 문제를 고친다. `runId`·`taskId`·terminal handle·작업 경로를 새 형식에서도 읽는다.
- **Stop hook의 "실행 중" 오판 해결**: 끝난 dispatch를 결과 없음으로 보던 문제를 고친다. 새 형식은 `outcome` 대신 `state`(`succeeded`/`failed`)로 결과를 알린다.
- 이슈 모드 sync의 worker 종료 판정이 문자열 `liveness`(`exited`)를 읽는다.
- 리뷰 snapshot 정리(`review.py cleanup --dispatch`)는 `worker-read`에 workspace가 없으면 `worker-show`에서 확인한다. 이전에는 확인 없이 지나갔다.
- 두 형식을 `integration.worker_view()` 한 곳에서 읽는다. 이전 Orca도 그대로 지원한다.

## 알아 둘 점

- 이슈 모드를 끈 뒤에도 owner 기록을 남기는 동작은 바꾸지 않았다. 이전 epoch worker의 fencing에 쓰인다.

## 기존 레포 적용

플러그인 업데이트 후 coordinator와 worker 세션을 새로 시작한다. 별도 설정 변경은 없다.
