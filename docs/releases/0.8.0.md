# FullOps Squad 0.8.0 변경안

## 범위

배포 방식을 "레포를 내려받아 설치기 실행"에서 GitHub 마켓플레이스 설치로 바꾼다. 실제 사용 중 드러난 flow-gate 오판도 함께 고친다.

## 마켓플레이스 배포

- 빌드된 `dist/native/fullops-squad`를 커밋한다. 루트 마켓플레이스 카탈로그(`.claude-plugin/marketplace.json`, `.agents/plugins/marketplace.json`)가 이 경로를 가리키므로 Claude Code·Codex·grok이 `tourbut/Fullops-Squad-plugin`을 마켓플레이스로 등록해 바로 설치한다. CI는 빌드 결과가 커밋된 `dist/`와 다르면 실패한다.
- `scripts/deps.py`를 플러그인에 넣었다. 마켓플레이스 설치가 넣지 않는 npm 도구(OCR CLI, Context7 MCP)와 사용자 범위 스킬·의존 플러그인을 `--host`로 설치하고 `--check`로 확인한다. 의존성 목록 `dependencies.json`은 빌드할 때 패키지에 들어간다. 개발용 `scripts/install.py`도 같은 목록을 쓴다.
- 세션 시작 hook이 빠진 필수 CLI를 알리고, `setup-fullops`가 첫 단계에서 승인 뒤 의존성을 설치한다.
- README·AGENTS.md 설치 안내를 마켓플레이스 기준으로 바꿨다. 체크아웃 설치와 agy는 `docs/development.md`에 둔다.

## flow-gate 오판 수정

- `worker-start --help`처럼 사용법을 확인하는 명령을 배정으로 보고 막던 문제를 고쳤다.
- dispatch 명령에 `handovers/to_<역할>.md` 경로를 넘기면 그 지시서 첫 줄의 과제 키를 인정한다.
- 첫 커밋 전 레포에서 역할을 판정하지 못해 세션 시작 안내가 빠지던 문제를 고쳤다.

## 기존 설치 전환

레포 체크아웃을 로컬 마켓플레이스로 쓰던 설치는 그대로 동작한다. 마켓플레이스로 옮기려면 CLI별로 기존 `fullops-squad` 마켓플레이스를 제거하고 README의 설치 명령으로 다시 등록한다. 그 뒤 모든 세션을 새로 연다.

## 검증

`tests/deps.py`를 추가하고 `tests/flow-gate.py`에 사례를 더했다. 격리된 설정 폴더에서 Claude Code·Codex가, 임시 등록으로 grok이 로컬 경로 마켓플레이스에서 설치됨을 확인했다. `npm test`가 통과했다. agy의 마켓플레이스 등록은 확인하지 못했다.
