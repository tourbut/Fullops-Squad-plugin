# Orca 역할 배정

역할·워크트리·브랜치는 1:1:1로 관리한다. 역할과 브랜치의 정본은 `fullops.json`의 `roles`다.
setup에서 레포에 필요한 역할만 생성한다. 역할 추가 시 setup을 다시 실행하고 아래 배정표를 갱신한다.
실제 repo id·경로·터미널 핸들은 전달 직전에 조회해 지시서에 기록한다.

| 역할 | 워크트리 이름 | 브랜치 | CLI | 기동 방식 |
|---|---|---|---|---|
| coordinator / 병합 책임자 | 기존 체크아웃 | 기본 브랜치 조회 | 현재 세션 | 기존 세션 |

각 등록 역할의 책임·CLI·모델·기동 명령을 위 표에 추가한다. 기획·설계에는 고성능 모델을,
범위와 완료 기준이 확정된 구현에는 비용이 낮은 모델을 배정한다.
원격 연결은 `fullops.json`의 `git`에 기록한다. worker는 해당 원격 브랜치를 추적하는 Orca 워크트리를 사용한다.

Orca가 지원하는 에이전트는 해당 버전의 agent 옵션을 사용한다. 별도 모델 옵션이나 미지원 CLI는 command 방식으로 기동한다. 같은 worker에 두 터미널을 중복 기동하지 않는다.
미정인 배정은 사용자가 정한 뒤 실행한다. 진행 중인 worker를 재사용하려면 현재 작업 종료와 세션 분리를 확인한다.
