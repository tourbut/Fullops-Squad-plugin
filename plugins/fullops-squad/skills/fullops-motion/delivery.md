# 작업 입력과 인계

현재 역할 인박스의 기존 절에 아래를 채우거나 원천 문서를 연결한다. 별도 중복 지시서/정본을 만들지 않는다.

## 작업 입력

- 목적·시청자·핵심 메시지·사용처, 제작/내용/검수 담당 역할
- 길이·폭/높이·FPS·화면 비율·출력 형식/codec/색 공간·알파
- 장면표: 시작/끝, 시각 내용·전환·실제 문자열·내레이션·음성 시작/끝
- 시간별 텍스트 정책과 예외, 브랜드·색·로고·금지 요소·참조의 역할
- 음성: 없음/사용자 음원/로컬 TTS, 언어·발음·음량·편집 조건
- 자산의 실제 경로·출처·라이선스·권리·필요 글꼴과 glyph, 읽기 전용 파일
- 비용: 무료 전용/허용 예산·Remotion 사용 자격, 로컬 렌더 승인 범위
- 엔진/공식 스킬 ref·버전/lock·입력→출력·보관 정책·완료/수락 기준

텍스트 정책은 새 작업에서 다시 정의한다. 예: 15초 영상은 `[0,13)` 텍스트 없음, `[13,15)` `함께 만드는 모션`만 허용. 경계는 FPS에 맞는 프레임으로 기록하며 12.966…/13/14.966…초를 검수한다.

## 로컬 기술 검사

시간은 초, 구간은 시작 포함/끝 제외로 기록한다. 계획된 텍스트 목록은 실제 렌더 화면과 대조한다. 필수 자산/음원은 실제 파일이어야 하며 음원 길이·타임라인 길이·허용 겹침을 확인한다.

```bash
ffprobe -v error -count_frames -show_streams -show_format -of json renders/v01/intro.mp4
ffmpeg -i renders/v01/intro.mp4 -map 0:a:0 -acodec pcm_s16le qa/v01/final-audio.wav
```

해당 버전 CLI의 FFprobe/FFmpeg 명령도 사용할 수 있다. 길이·폭/높이·FPS·프레임 수·stream 종류를 장면표의 기대 값과 대조하고 누락된 정보를 추정하지 않는다. 검사 입력/도구 오류는 unavailable, 규격 위반은 failed다. 보고서·추출 자산은 새 실행 경로에 저장한다.

## 검수 기록

기존 `qa-reports/<과제 키>-test/<실행>/`에 다음 근거를 연결한다.

| 검사 | 필요한 근거 |
|---|---|
| 실행/규격 | 정확한 명령·exit·경과 시간·도구/OS/CPU·source SHA/dirty·실제 ffprobe JSON: 길이/크기/FPS/프레임 수/영상·음성 스트림 |
| 시각 | 첫/장면 대표/전환 직전·직후/텍스트 정책 경계/마지막 프레임, 파일 경로와 판정 |
| 타이포/내용 | 한글 glyph·글자 잘림/겹침/크기·정확한 모델명/로고·화살표/실제 기능·운영 상태 |
| 음성 기술 | 입력 음원 길이·각 대사 시작/끝·허용 겹침·tail 잘림·출력 PCM peak/clipping/무음·최종 믹스 |
| 청취 | 실제 최종 영상/음원의 청취 담당·발음·억양·명료도·음량 판정. 미청취는 not_run |
| 비용/권리 | 호출 대상·허용 범위·확인된 비용 또는 unknown, 자산/글꼴/음성/툴 라이선스 |
| 재렌더 | 깨끗한 다른 폴더에서 소스/lock/자산/명령으로 재렌더, 규격·시각 프레임 비교, 미실행/제한 |

HyperFrames `check`의 browserSkipped/빈 audit는 통과가 아니다. exit 0만으로 창의적 수락을 선언하지 않는다. 자동 검사는 시각적 텍스트 부재·자연스러운 발음·내용 사실을 입증하지 못한다. 각 항목에 `passed|failed|not_run|unknown`과 이유를 남긴다.

필요한 프레임은 버전 CLI의 snapshot/still 또는 최종 MP4에서 FFmpeg로 추출한다. 처음/끝의 시간 대신 정확한 `0`/`N-1` 프레임도 확인한다. 오디오는 실제 출력에서 PCM을 추출해 분석하고 따로 청취한다. 이미지 판정 없이 파일 존재만으로 검수하지 않는다.

## 인계 완료

- 최종 영상 버전/경로와 수정 가능한 코드·렌더 진입점
- 음원·자산·글꼴 파일 또는 접근 가능한 보관 위치, 출처·라이선스·생성/사용 조건
- 대본·장면표·타이밍/구간 정책과 정확한 입력→출력 대응
- lock·실제 도구/브라우저/FFmpeg 버전·재렌더 명령과 미리보기 실행/URL
- 대표 프레임·기술/시각/내용/청취 검사 결과와 미확인 항목
- 이전 버전/실패/중단 근거 보존, 다음 담당·재개 조건

worker 완료와 제품 최종 수락을 분리한다. 수정 요청은 같은 과제의 새 출력 버전으로 반영한다. 테스트/렌더를 재시도할 때도 이전 실패 증거와 성공 파일을 유지한다.
